# Contributing to VaultPeer Phonebook

The source is open to use as per the [LICENSE](./LICENSE).

Be aware that **any pull request or issue may be closed without explanation**.

## Issues

- Feature requests are welcome.
- For bug reports, please provide steps to reproduce and relevant server logs.

## Pull Request

Newer contributors are encouraged to start small and simple.

- Keep pull requests focused on a single feature or bug fix
- Provide a clear description of changes
- Test locally with `npm start` before submitting
